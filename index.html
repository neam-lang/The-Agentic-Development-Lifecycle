The Agentic Development Lifecycle

Delegated execution under human supervision — an evidence-graded account of what changes when agents become the primary labour of software engineering, and what has to be built to replace what stopped working.

The spine. SDLC assumed the bottleneck was producing code. ADLC assumes the bottleneck is verifying and directing it.

The argument in one figure

One price fell, and six goods that were resting on it fell together. Everything else in the book follows from that.

Four rings of control

Each ring exists because the one inside it saturates, and each outer ring makes the inner ones cheaper. This is an argument, not a taxonomy.

The evidence, plotted

Five studies, one gradient. The two most rigorous sit at opposite ends — rigour does not determine sign, task selection does.

What teams actually built

Böckeler's quadrant, populated with adoption data from 2,853 repositories. The field invested in the weakest cell at roughly 29 to 1.

The double loop

The inner loop changes the software. The outer loop changes what governs its construction. Their only connection is artefacts.

The autonomy ladder

A ceiling set by harnessability × blast radius, implemented as capabilities the agent does not hold.
